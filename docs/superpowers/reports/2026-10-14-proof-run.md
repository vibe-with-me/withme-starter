## 1. Verdict

The acceptance sentence reads: "Fresh clone → make-it-yours → customize-gathering → extend-profile → go-live, as a fake derivation, timed. This is the acceptance test for 'derivations are no longer barebones.'"

**Covered in two halves.** No single run was a fresh clone through go-live. Two runs covered the sequence between them, each by fresh subagents that saw only the skill text and a brief, with START/END stamps on every run: Run Club took a fresh clone through the skills locally, with no go-live; Golf with Me took a fork rebuilt on a fresh starter tree through the skills and a real go-live. The goal, "derivations are no longer barebones", is supported (below); the criterion as literally written was met in two halves, not in one run.

- **Run Club** (2026-10-12, local only, throwaway): a fresh GitHub clone of `main` at 511a26c through make-it-yours, customize-gathering (nouns, the `/runs` URL rename, one required field), extend-profile (both tiers, a required card field with a format rule), provision-tags (local), the full gate and a simulator pass. Clean-path skill time **50 min**; whole clean path including gate and simulator **65 min**. Gate at the end: db 87, contract 37, nfc 48, API e2e 67, Playwright 14, all green.
- **Golf with Me** (2026-10-13/14, a real product): the existing fork rebuilt from a byte-identical copy of the starter at 250edfd, through design-direction (an uplift), make-it-yours with the real `project_id` rename, customize-gathering, extend-profile (card only, one typed field), add-destination-type, provision-tags (local), gate, simulator, and **go-live for real**. Skill time **74 min**, gate and simulator 22 min. Live at https://golfwithme-web.golfwithme.workers.dev and https://golfwithme-api.golfwithme.workers.dev; EAS update group `16e2daa9-474b-47e5-a0c8-8c7dafc85964` on branch `demo`. Final gate: db 80, contract 44, nfc 48, API e2e 67, Playwright 14.

A derivation now starts with the safety core and its RLS suite, gatherings with membership and tag pointers, Connections, avatars, My tags, account deletion, the store pointer, provisioning, e2e and Playwright, and CI, and the skills take it from there to a branded, customized, live product in about two hours of agent time. That is no longer barebones.

**Not proven.**

- **The acceptance sentence as one run.** Fresh clone through go-live never ran end to end: Run Club stopped before go-live, and golf started from an existing fork rebuilt on the starter's tree, not a fresh clone.
- **Tailgate.** Deferred by Alex on 2026-10-13 until the sporting-events data source is decided. Only one real product was rebuilt.
- **Production provisioning and physical tags.** provision-tags §2–§4 never ran: golf has no custom domain and rule 6 forbids encoding a `workers.dev` origin. `readTagUid` on a chip is untested.
- **An EAS build.** go-live publishes an update; no build targets golf's runtime, so no device loaded it. The automated mobile checkpoint is the export check only.
- **The `project_id` rename on Run Club.** Skipped (Decision 6, the shared stack). It ran for real on golf (G4) and the fixed step 6 order worked first time.
- **`supabase projects create`.** Golf reused and reset its existing project, so the create path and the free-project-limit branch are untested.

**Caveats.** The clean-path minutes measure the *fixed* text: Run Club's make-it-yours, customize-gathering, extend-profile and provision-tags each needed 2–3 runs, and the minute counted is the last. Golf's skills ran once each; their fixes are text-only and were "verified, not re-run" against the fork. Go-live was not timed as a clean run: it spread over two days with Alex's logins, dashboard steps and checks as pauses. The one core bug that go-live found (the profile-less delete loop) was caught only by Alex's hands-on sign-up and delete, not by any automated checkpoint. The golf PR (vibe-with-me/golf-with-me#5) is open, not merged; teardown has not run.
